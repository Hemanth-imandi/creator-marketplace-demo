Creator Marketplace — Business Demo Beta
Overview
A temporary, interactive HTML prototype exploring the business logic and user experience of a creator campaign marketplace.
Purpose
Created as a working concept to support project planning, demonstrate potential workflows, and gather feedback on the proposed business model.
Features
	•	Brand, creator, and admin dashboard previews
	•	Campaign creation and discovery
	•	Creator application and content review workflows
	•	Analytics and payment dashboard mockups
	•	Market selection and country-based views
	•	Messaging and support demonstrations
Status
Beta concept — work in progress.
This is a front-end prototype using sample data. It does not include production authentication, a backend database, real payment processing, or live social media integrations.
Run locally
Open index.html in a modern web browser.
